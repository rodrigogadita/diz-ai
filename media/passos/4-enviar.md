# Envie sem tocar no teclado

Termine a fala com **"pode enviar"**, **"manda ver"** ou **"manda bala"**. Ou aperte `Ctrl+Alt+Enter`.

O prompt cai na caixa do **Claude Code**. Você revisa e aperta Enter.

Usa outra ferramenta? Em **Configurações > Diz Aí > Destino** escolha o chat do VS Code (Copilot), o terminal (Claude Code CLI, Aider, Codex) ou só copiar.

Quer começar outro assunto do zero? **Limpar** apaga as duas caixas e abre uma conversa nova no Claude Code.

Tudo fica no **Histórico**, logo abaixo do painel: clique para trazer um prompt de volta ou reenviar.
