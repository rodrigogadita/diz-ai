# Modos e motores

**Modos de escrita**

| Modo | Para quê |
|---|---|
| Prompt estruturado | O padrão: parágrafo ou seções, conforme o tamanho |
| Texto limpo | Só limpa e corrige, na ordem da fala |
| Relato de bug | O que acontece, o esperado, como reproduzir |
| Nova funcionalidade | Objetivo, comportamento, regras, pronto quando |
| Refatoração | O que mudar e o que não pode quebrar |
| Revisão de código | O que revisar e com que foco |
| Pergunta | Uma pergunta direta com o contexto |

Crie os seus em `dizAi.modosPersonalizados`.

**Motores de voz**

| Motor | Destaque |
|---|---|
| Windows (Win+H) | Padrão, sem configurar nada |
| Whisper | O mais preciso: Groq, OpenAI ou servidor local |
| VS Code Speech | Offline |
