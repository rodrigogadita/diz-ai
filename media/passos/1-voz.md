# Prepare o ditado do Windows

O motor padrão do Diz Aí é a digitação por voz do Windows (**Win+H**). Ela reconhece muito bem o português e já pontua.

1. **Configurações > Hora e idioma > Digitação > Digitação por voz**: ligue a **pontuação automática**.
2. **Configurações > Privacidade e segurança > Fala**: ligue o **reconhecimento de fala online**.
3. Deixe o teclado em **Português (Brasil)**. O ditado segue o idioma do teclado.

Não usa Windows ou quer trabalhar offline? Troque o motor para **VS Code Speech**. Quer a máxima precisão com termos técnicos? Use o **Whisper**.
